## 4. The arithmetic this PR changes, and what it predicts

The fit test's price for the Feed's five lenses under `fill`, which is what both in-column callers
render and now name:

```
before:  need = 8 + 2(n−1) + n · P          P = the probe span's own width
                                            = label + icon 20 + gap 8 + padding 16 + border 2
after:   need = TRACK + GAP(n−1) + n · seat(widest)
         seat(w) = max(44, w + 2·14 + 2·1 + 20 + 8)      (`icons` set)
```

The probe's recorded numbers therefore drop by 46 on every line: the glyph, its gap, the seat's
padding and the seat's border moved out of the probe's markup and into `seat()`, where one arithmetic
change can no longer pass silently through the probe. The seat's own price rises by 12, because the
side padding goes 8 to `PAD` 14 (item 47).

Measured locally against `wrangler pages dev dist` on chromium, `SPECIAL=shell`, 298 of 298 checks
passed and the record read:

`seat(72) = max(44, 72 + 28 + 2 + 28) = 130`, so `need = 8 + 8 + 5 × 130 = 666`. That is above every
